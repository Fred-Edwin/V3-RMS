0 · Set up

Docker (Postgres + Redis) up, then the API and the web app:

cd ~/Projects/V3-RMS
git switch feat/m6-s4-history-opening
docker compose up -d postgres redis

# terminal 1 — API (port 4000). Restart it if it was already running: the new routes need a fresh process.
cd backend && pnpm dev

# terminal 2 — web (port 3000)
cd frontend && pnpm dev

Seed the data (from backend/). The first script stocks the departments and writes yesterday; the second adds three older closed days (one reopened once) and today's pending Kitchen opening:

npx tsx src/scripts/seed-branch-day-dev-fixtures.ts --state=open --block=none
npx tsx src/scripts/seed-branch-day-history-dev-fixtures.ts --opening=pending
