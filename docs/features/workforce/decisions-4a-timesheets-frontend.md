# Workforce slice 4a (Timesheets, overtime, My time, requests) front end: decisions made without the owner

Written 19 Oct 2026 on branch `feat/workforce-4a-timesheets-frontend`. Each row is a question Paper or the brief left open, what was built, why, and what changing it takes. Nothing here changes what a branch whose new clock is off sees or can do. Code: `frontend/features/workforce/timesheets/` (periods, week, overtime, report, requests, mine), the Home cards in `features/workforce/home/cards/timesheet-data.ts`.
