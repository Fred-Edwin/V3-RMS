Redesigned Color System

Slate — Unread / not yet seen
Blue — Read / seen (familiar from WhatsApp ticks)
Orange — Pending acknowledgement (action needed)
Green — Acknowledged / complete

Notices use orange-family (EA580C) instead of muddy amber (#92650A) — same warmth, much higher saturation and contrast. Broadcasts use blue for read-tracking since "read receipt" = blue ticks in users' mental model.
