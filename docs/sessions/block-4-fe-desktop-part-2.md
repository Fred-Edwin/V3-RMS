## Gotchas learned in Part 1
- **Servers (lane 6):** frontend on 3106 (`http://lane6.localhost:3106`), API on 4106. The API must be running the current code: it had been started before the access table gained the `branch_day.*` rows, so the Branch Manager had no Branch day capability until it was restarted (`pnpm dev` in `backend/`; kill only the PID whose working directory is `lane-6/backend`). Part 1 left both running: the API from `pnpm dev`, the frontend from `pnpm exec next dev -p 3106`. `pnpm build` shares `.next` with the dev server, so stop the dev server (by PID, check its working directory) before building and restart it after. Memory is tight (about 1 GB free): one browser tab, stop servers you do not need.
- **Browser tooling:** `take_snapshot` and `wait_for` return the whole sidebar and are very large; prefer `evaluate_script` with a polling loop and read just what you need. To switch role, clear cookies, local and session storage in the page, go to `/login`, fill the two inputs with the native value setter and click "Sign in" (`evaluate_script`). `emulate` sets the viewport reliably (`resize_page` did not). The permissions cache is in `sessionStorage` key `central-store-permissions`; clear it after a back-end restart. The first dev compile of a route can take over ten seconds and times out `navigate_page`; poll instead of retrying.
- **React StrictMode** calls effects twice in development: a one-shot mock failure is swallowed by the second call (the mock fails for 1.5 s instead). `useIdempotencyKey()` returns a new object every render: depend on its `renew` function, not the object (this wiped typed figures in Part 1).
- **Drawers:** keep a drawer mounted while it closes (flip `open`, keep the item) or Radix cannot hand focus back to the opener; when the opener row disappears, move focus to the next thing to do (`returnFocus` ref in `today-screen.tsx`).
- **Paper facts that differ from the spec text:** step 9 shows no department cards and no blocker rows after the close; a department card's "Counted 6:20 pm" line is a sibling of the Used today block, not inside it (card height 256); the mock's usage-entry count is the real number of items that used something (36), not Paper's invented 43 (contract §0.1).
- **Shared files the phone session may also touch:** `features/inventory/_shared/components/block2-phone-parts.tsx` (`PinField`, `Chip`), `_shared/lib/block2-words.ts` (`ChipTone`), `_shared/components/drawer-shell.tsx`, `dispatch/index.ts`. Report any you change.
