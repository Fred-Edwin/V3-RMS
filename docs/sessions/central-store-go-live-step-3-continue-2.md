- Tests mock repositories and use `prisma: { $transaction: (fn) => fn({}) }`; look at `orders/orders-service.test.ts` for the pattern, including the route-matrix check of capabilities.
- `vi.clearAllMocks()` keeps implementations: reset a `mockResolvedValue` you set in an earlier test when a later test expects the default.
- `matchOrderLine` (never guesses; a different named pack is "not on file") is what receiving and the pack-mismatch check share.
- Supplier module tests mock `supplier-purchasing-reads` through `supplier-test-fixtures.ts` `purchasingReadsMocks()`.
