7. **Errors and the States kit:** Chapter 16 "When things go wrong" rows and the States kit (loading, empty, error, locked, no permission, offline) become one shared set of messages: specify the message table (copy, where it shows, what the user can do), including a site not approving timesheets (Remind), a paid month, a corrected payslip after the bank file, a wrong PIN, a request on an approved month, a padlocked Change.
